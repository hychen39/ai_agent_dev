
# LangChain Agent 開發環境建置與 Python Notebook 使用

## 前置需求

- Python 套件與專案管理工具 `uv`
- Python 版本 >=3.12、<3.14
- OpenAI API 金鑰（用於使用 OpenAI 模型），或其他大型語言模型（LLM）的 API 金鑰（例如 Anthropic、Cohere 等）
- 建議使用 VSCode 整合開發環境（IDE）進行開發與除錯。

## 大型語言模型 API 金鑰

請自行準備大型語言模型的 API 金鑰。
本課程不提供 API 金鑰，也不提供任何補助。

- 付費大型語言模型 API 金鑰：OpenAI、Anthropic、Cohere 等。
- 免費大型語言模型 API 金鑰：GroqCloud、Google AI Studio（Gemini API）。
